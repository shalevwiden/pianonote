Sampled instruments for Peak Notes.

Source: Musyng Kite General MIDI soundfont, packaged for the web by
[midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts).
License: [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).

Local layout:

    assets/samples/piano/*.mp3
    assets/samples/epiano/*.mp3
    assets/samples/harpsichord/*.mp3
    assets/samples/eguitar/*.mp3

Files are named with MIDI.js flats, e.g. `C4.mp3`, `Db4.mp3`, `A0.mp3`.

Refresh from the network:

    python3 scripts/fetch_samples.py
